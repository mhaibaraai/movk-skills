# 审查维度与检查清单

三类能力对应三组检查项。每条问题都要落到「位置 + 原文 + 问题 + 建议」四要素，缺任何一项都不算完成审查。

## 问题分级

| 级别 | 判定标准 |
| --- | --- |
| 必须修改 | 会导致合同无效、金额错误、责任缺失或与签约依据冲突的问题 |
| 建议修改 | 表述不严谨、条款对己方不利但不致命、与标准模板存在实质差异 |
| 提示关注 | 错别字、标点、编号不连续这类不影响效力的问题，以及需人工核对的疑似 OCR 误识 |

## 一、基础文本审查

**金额**（最易出错，逐项核）

- 大写与小写金额是否一致（含币种、单位「元」「万元」的口径）
- 分项金额之和是否等于合同总价；单价 × 数量是否等于分项金额
- 含税/不含税口径是否明确，税率与价款是否自洽
- 合同价与签约依据（中标通知书、询比价结果审批表、会议纪要）中的金额是否一致

**日期与期限**

- 签订日期、生效日期、履行期限、质保期起算点是否齐全且不矛盾
- 期限表述是否可计算（「30 日内」要写明自何时起算，是否为工作日）

**主体与格式**

- 甲乙双方名称是否与公章、统一社会信用代码一致，地址与联系人是否填写
- 是否残留未填写的空白项（`____`、`XXX`、模板占位符）
- 条款编号是否连续，条款交叉引用（「见第 X 条」）是否指向存在的条款
- 附件是否在正文中被引用且实际随附

**文字**

- 错别字、漏字、重复字
- 标点误用（全角半角混用、括号不成对、分号句号混乱）

## 二、风险合规校验

按以下条款逐项核对「有没有」与「对谁有利」：

- **付款**：预付款比例、进度款节点、尾款与质保金比例、付款前提（验收合格、发票到达）
- **违约责任**：双方违约责任是否对等，违约金比例与上限，逾期交付/逾期付款的计算方式
- **质量与验收**：验收标准、验收期限、不合格的处理方式、质保期与质保责任
- **知识产权**：成果归属、许可范围、第三方侵权的责任承担（技术服务类合同必查）
- **保密**：保密范围、期限、违约后果
- **安全环保**：施工与运维类合同的安全责任划分、事故责任、资质要求
- **廉洁**：廉洁从业条款是否具备（国企合同的常规必备项）
- **分包与转包**：是否允许、是否需书面同意、禁止转包的表述
- **不可抗力**：定义、通知义务、后果处理
- **合同解除**：解除情形、通知程序、解除后的结算方式
- **争议解决**：诉讼或仲裁二选一且唯一，管辖地明确且对己方不构成不便
- **履约担保**：是否约定保证金/保函及退还条件

任一条款缺失即为「条款缺失」，存在但对己方明显不利即为「风险提示」，两者在报告里分开写。

## 三、合同模版校验

**与标准模板比对**：`get-contract-template` 返回的是模板全文，逐条对照，输出三类差异——模板有而合同无（缺失）、合同有而模板无（新增，需说明是否合理）、两者都有但实质改写（改动点与影响）。模板正文里没写的条款不算缺失。

**与签约依据的上下游一致性**（本项最能发现实质问题）：

- 合同价 vs 询比价结果审批表的中标价
- 合同范围 vs 会议纪要/立项审批中批准的建设内容与数量
- 合同乙方 vs 中标单位名称
- 合同工期 vs 会议纪要中要求的完成时间

不一致的一律列为「必须修改」，并写明两边的原文与出处文件名。
